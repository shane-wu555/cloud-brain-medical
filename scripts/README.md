# 脚本目录

用于放置数据库初始化、迁移、种子数据和运维辅助脚本。

## 患者端联调测试数据

- `seed-patient-app-smoke-data.sql`
  作用：生成患者端登录注册、实名校验、AI 问诊后线上挂号所需的本地测试数据。
- `cleanup-patient-app-smoke-data.sql`
  作用：清理上面脚本写入的测试数据。

默认测试账号：

- 已实名患者：`13800000011 / abc12345`
- 未实名患者：`13800000012 / abc12345`

说明：

- 这类一次性或本地联调用测试数据，不建议直接改现有 Flyway 迁移。
- 更合适的做法是放在独立 SQL 脚本里，按需手工执行，避免污染正式基线数据。
- 如果未来你们希望“每个新环境启动后都自动带一批演示数据”，再单独新增 Flyway seed migration 会更合适。
